## 二、规律推断

1. **两阶段处理**：
   - 阶段 1（流式 markdown）：按主题大块切，5-6 章节，每章节 4-7 字标题
   - 阶段 2（最终细分镜）：每章节内部按子句逗号切，每子句独立成镜
2. **标题词典**（受控词汇）：
   - 概念维度：`效果`、`妆效`、`功能`、`场景`、`人群`、`信息`、`特点`
   - 动作维度：`展示`、`评价`、`描述`、`说明`、`补充`、`验证`、`推荐`、`举例`、`建议`、`号召`
   - 组合：`<对象><动作>` 形成 4-8 字名字
3. **内容保留**：原文逐字不改，仅做切分；问号等可保留
4. **粒度**：每镜 2-15 字，超长不出现
5. **特殊处理**：
   - 单字 / 双字短句独立成镜（"抖音"、"看看看看"）
   - 不省略平台信息 / 行动号召
6. **输出顺序**：严格按原文出现顺序

## 三、反推 Prompt（双阶段方案）

### 阶段 1：主题切块 prompt

```
你是文案分镜助手。把以下口播文案按主题切分成几个章节，每章节 4-7 字小标题概括本章核心。

输出严格 markdown 格式：
## <标题>
<原文逐字保留的内容>

## <标题>
<原文逐字保留的内容>
...

要求：
1. 标题 4-7 字，必须高度概括本章节卖点 / 主题（例如：遮瑕效果、妆效特点、防水功能、使用场景）
2. 内容保持原文逐字不改，不增不删
3. 相邻语义相关的句子归到同一章节，不跨主题混合
4. 章节数建议 3-7 个；过少则用户感知粒度差，过多则破坏主题感

口播文案：
{TEXT}
```

### 阶段 2：精细分镜 prompt

```
你是文案分镜助手。把以下章节化文本切分成精细分镜，每分镜对应一个独立的镜头。

输入是阶段 1 的 markdown 章节文本，输出严格 JSON：
{"shots":[{"name":"...","content":"..."},...]}

切分规则：
1. 每个分镜对应原文的 1 个独立子句（按 `，` `。` 切）
2. 内容保持原文逐字不改，标点可保留可去除
3. 单字 / 双字 / 短词独立成镜（如"抖音"、"看看看看"），不强行合并
4. 长子句保留为单镜（如 13 字以上），不再二次切

命名规则（4-8 字）：
- 格式：<对象><动作>
- 对象词典：效果、妆效、功能、场景、人群、信息、特点、版本、产品
- 动作词典：展示、评价、描述、说明、补充、验证、推荐、举例、建议、号召
- 示例："遮瑕效果展示"、"妆效描述"、"运动场景验证"、"行动号召"、"平台信息"

严格按原文顺序输出，不调换、不省略。

章节化文本：
{MARKDOWN_FROM_STAGE_1}
```

## 四、单阶段简化 prompt（推荐先上）

合并两阶段为单 prompt，兼顾效果与时延。失败时回退到正则切句。

```
你是文案分镜助手。把以下口播文案切分成精细分镜，每分镜对应一个独立镜头。

严格 JSON 输出（禁止 markdown code block 包裹）：
{"shots":[{"name":"...","content":"..."},...]}

切分规则：
1. 每个分镜对应原文的 1 个独立子句（按 `，` `。` `？` `！` 切）
2. content 保持原文逐字不改，可保留 / 去除标点
3. 单字 / 双字 / 短词独立成镜（如"抖音"、"看看看看"）
4. 严格按原文顺序，不调换、不省略

name 命名规则（4-8 字）：
- 格式：<对象><动作>
- 对象词典：效果、妆效、功能、场景、人群、信息、特点、版本、产品、画面、动作
- 动作词典：展示、评价、描述、说明、补充、验证、推荐、举例、建议、号召、提示
- 示例：遮瑕效果展示 / 妆效描述 / 运动场景验证 / 行动号召 / 平台信息

口播文案：
{TEXT}
```

## 五、降级策略

LLM 调用链：

```
LLM 单阶段 prompt
  │
  ├─ 成功 + JSON 合法 → 直接用
  ├─ 成功但 JSON 解析失败 → 提取 markdown ## 段，每段独立成镜，name 用 ## 标题
  └─ LLM 调用失败 → 回退到正则切句（现版 decomposeText），name 默认 "分镜N"
```

## 六、落地接口

后端：

```
POST /cm/script/decompose
Request: { text: string, options?: { maxShots?: number, style?: 'default'|'kol' } }
Response: {
  status: 'SUCCEEDED' | 'PARTIAL' | 'FAILED',
  shots: [{ name: string, content: string }],
  provider: string,
  fallbackUsed?: boolean,
  errMsg?: string
}
```

复用 `LlmAdapter.chat()`，传 system prompt + user prompt。

前端：

`ScriptFission.tsx` 步骤 1 → 步骤 2 时调 `cmRemote.scriptDecompose(text)`，同步 loading state，失败时调 `decomposeText()` 兜底。
